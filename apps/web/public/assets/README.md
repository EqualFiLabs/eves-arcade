# Placeholder assets

These are tiny stand-in files (4x4 PNGs, ~0.1s silent OGGs) generated so the
Phaser loader succeeds and the game is playable from Task 10 onward. They are
NOT final art/audio — the real assets are produced in later art/sound tasks and
overwrite these files in place. Keys and paths are defined in
`packages/content/src/assets/asset-manifest.ts` (data-driven, Req 16.4).
